# 올팍 출차시계

올림픽공원 공연이 끝난 밤, 주차장에서 "지금 나가면 막히는지, 몇 분 뒤 풀리는지"를 알려 주는 정적 웹앱(PWA)입니다.

- 한국체육산업개발 실시간 주차현황 API(공공데이터포털 15168686)의 5분 변화량
- 주차장 입출차 정보 2024(15138735)에서 재현한 공연 밤 감소 곡선
- 올림픽공원 공연 일정

서버 없이 정적 호스팅만으로 동작합니다. 기록 체험이나 `?demo`는 기록 목록에 있는 최신 실측을 우선 엽니다. 아직 더 최신 실측이 없으면 2025-12-06 입출차 재현(부분 수집)을 보여줍니다. `?demo&record=2024-07-20&at=22:00`으로 예전 기록과 시각을 직접 지정할 수 있습니다.

공연 일정은 GitHub Actions에서 3시간마다 한국체육산업개발 공식 목록을 수집합니다. 목록이 응답하지 않으면 공식 캘린더를 사용합니다. 화면은 공지된 종료 시각을 우선하고, 그 값이 없으면 시작 시각에 공지 또는 별도로 확인한 러닝타임을 더합니다. 러닝타임까지 없으면 종료 시각을 추정으로 표시합니다.

자동 수집 후 Pages 재배포 없이도 갱신되도록 브라우저는 공개 `main`의 공연 일정과 실측 기록 JSON을 읽습니다. 공개 파일에 연결할 수 없으면 Pages에 배포된 파일을 사용합니다.
